# Outlier

Rarest-answer trivia. Each prompt ("Name a dog breed") has many correct answers; the rarer the answer, the more points. Score is shown as distance from the crowd, in σ (100 points = 1σ).

- **Who:** friends and casual players on phones and PCs, mostly in short sessions; also party play in one room.
- **Modes:** Daily (same 7 prompts worldwide, one try, global leaderboard and answer stats), Unlimited (any genre, endless), Multiplayer (rooms with a 6-digit code or invite link, quick match with strangers).
- **Genres:** General, Minecraft, Music, Gaming, Geography, History, Animals, Food, Sports, Screen (movies & TV), Science.
- **Constraints:** free to run (Render free web service), English only, no accounts, works in any modern mobile or desktop browser.
- **Tone:** playful, quick, a little nerdy about statistics. Never preachy.

Assumptions (inferred from the brief, not confirmed): name "Outlier", σ scoring, 30-second prompts, duplicate answers in multiplayer score half.
